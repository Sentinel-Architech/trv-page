The Remote Viewer (TRV)

For We The People. By Architech | The Remote Viewer.

What it is

TRV is a phone app project.

It is local-first. Your data stays on your phone.

It is privacy-focused. No tracking.

It is built to run without big corporate platforms.

It is for We The People.

Status: honest

TRV is a test project. It is not finished.

Latest tagged release: v0.9.6, October 21, 2026.

What exists now

  • A test build for Android phones.
  • It ran on real phones on October 20, 2026.
  • A helper called the Sentinel. It follows fixed keyword rules.
  • Notes you save stay on your device.
  • Messaging between two phones on the same local network.

What is not done yet

  • No real AI model in the app yet.
  • Solana is not deployed. Nothing runs on-chain.
  • No signed phone build yet. Only a test (debug) build.
  • Some parts are still placeholders, like real encryption and signing.
  • The code is not public yet. A code release plan is coming.
