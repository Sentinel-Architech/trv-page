How to install — 4 easy steps

  1. Tap DOWNLOAD above. A file will come down to your phone (about 34 MB — roughly the size of a short video). Wait for it to finish.
  2. Tap the downloaded file. You can tap the "download finished" message at the top of your screen, or find the file in your Downloads folder.
  3. Your phone will probably show a warning. This is normal — Android warns about every app that does not come from a store. Tap Install anyway. If your phone instead says it is "not allowed to install unknown apps," tap Settings, turn on Allow from this source, go back, and tap the file again.
  4. Tap Open. That's it — The Remote Viewer is on your phone.

What exists now

  • A test build for Android phones.
  • It ran on real phones on October 20, 2026.
  • A helper called the Sentinel. It follows fixed keyword rules.
  • Notes you save stay on your device.
  • Messaging between two phones on the same local network.

What is not done yet

  • No real AI model in the app yet.
  • The Solana token is not launched. The identity registry runs on Solana devnet (a test network) since November 17, 2026.
  • No signed phone build yet. Only a test (debug) build.
  • Some parts are still placeholders, like real encryption and signing.
  • The app download is public. The source code stays private.
